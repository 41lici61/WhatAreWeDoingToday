
# 🎲 What Are We Doing Today? (WORK IN PROGRESS)

An Android application built in **Java** that helps you decide what to do when you can’t choose.

The app randomly selects an activity from a set of predefined options, or lets users create their own custom list of choices and pick one at random.

---

## 📱 About the App

**What Are We Doing Today?** is a simple but useful decision-making tool designed to eliminate indecision in everyday situations.

You can:

* Choose from **10 predefined activities**
* Create your own **custom list of options**
* Let the app **randomly pick one for you**

Perfect for:

* Friends not knowing what to do
* Couples deciding plans
* Solo users looking for inspiration
* Reducing decision fatigue

---

## ⚙️ Features

* 🎯 Random selection system
* 📋 10 built-in activity options
* ✍️ Custom user input list
* 🔁 Instant re-roll option
* 📱 Simple and intuitive Android UI
* ⚡ Lightweight and fast performance

---

## 🧠 How It Works

1. User opens the app
2. Chooses between:

   * Predefined activities
   * Custom list input
3. App randomly selects one option
4. Result is displayed instantly

---

## 🛠️ Tech Stack

* ☕ **Java** – Main application logic
* 📱 **Android SDK** – Mobile app framework
* 🎨 **XML Layouts** – UI design
* 🔀 **Random API (Java Util)** – Selection engine
